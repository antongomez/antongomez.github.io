# Personal Portfolio

Source code for my personal portfolio — built with React, Vite, and Tailwind CSS v4. Available in English, Spanish, and Galician.

## Stack

- **React 19** + **Vite 8**
- **Tailwind CSS v4**
- **React Router DOM v7**
- **i18next** — EN / ES / GL

## Development

```bash
npm install
npm run dev
```
